# The ABC System

ABC is an imperative programming language and integrated development environment
(IDE) that is easy to pick up and intuitive to use.

If you are looking to run the test suite, go to the [TESTS.md](./doc/TESTS.md)
file.

## HOW TO BUILD FROM SOURCE

See [BUILD.md](./BUILD.md) for details.

After installing the dependencies, run the following:

```sh
make -j`nproc`
```

When you want to clean up the build outputs, run

```sh
make clean
```
